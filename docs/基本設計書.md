# 基本設計書 (Basic Design Document)

## 1. はじめに

本書は、「Norunos Platform」の基本設計（外部設計）について記述する。要件定義書に基づき、システムの構成、画面の振る舞い、データ構造の概要を定義する。

## 2. システム構成

### 2.1. 技術スタック

本システムは、以下の技術を用いて構築する。

- **Frontend**: React, TypeScript, TailwindCSS
  - UIコンポーネントの構築およびユーザーインタラクションの処理。
- **Backend (Core)**: Tauri 2.0 (Rust)
  - システムリソースへのアクセス、ファイル操作、データベース操作、ウィンドウ制御を担当。
  - 高速かつメモリ安全なロジック実装。
- **Database**: SQLite
  - アプリケーションデータ（タスク、設定、メタデータ等）の永続化。
  - ローカルファイル（SQLite DBファイル）として保存。

### 2.2. アーキテクチャ概要

Tauriの推奨パターンに従い、FrontendとBackendの役割を明確に分離する。

- **UI Layer**: ReactによるSPA (Single Page Application)。Rust側とは非同期コマンド (`invoke`) で通信する。
- **Core Layer**: Rustによるビジネスロジック。状態管理 (`AppState`) およびデータ永続化を担当する。

## 3. UI/UX設計

### 3.1. デザインコンセプト

- **没入感**: OS標準のウィンドウ枠を排除し、コンテンツに集中できるデザインとする。
- **透過性**: ウィンドウ背景に透過効果を持たせ、デスクトップ環境との調和を図る。

### 3.2. ウィンドウ構造

- **フレームレスウィンドウ**: `decorations: false` に設定。
- **カスタムタイトルバー**: アプリケーション上部に独自のドラッグ領域およびウィンドウ操作ボタン（最小化・最大化・閉じる）を配置する。

### 3.3. 画面一覧

1. **Dashboard**: アプリ起動時のホーム画面。各機能へのショートカットを表示。
2. **ToDo List**: タスク一覧表示。サイドバーにグループリスト、メインエリアにタスクカードを表示。
3. **Calendar**: 月カレンダー表示。日付クリックで詳細ダイアログを表示。
4. **Gantt Chart**: タイムライン表示。
5. **Notes**: 2ペイン構成（サイドバー：ファイルツリー、メイン：エディタ/プレビュー）。シンタックスハイライト、スクロール同期をサポート。
6. **Books**: 書籍管理画面。書籍の登録・ステータス管理、読書進捗の可視化、読書メモの作成・管理（Markdown対応）。
7. **Mind Map**: キャンバスベースのダイアグラムエディタ。
8. **Settings**: アプリケーション設定画面。

## 4. データ設計

### 4.1. データ保存方式

データの特性に応じて、SQLiteデータベースとファイルシステムを使い分ける。

| データ種別 | 保存先 | 理由 |
| --- | --- | --- |
| タスクデータ | SQLite | 複雑なクエリ（検索、ソート、集計）が必要なため。 |
| カレンダーイベント | SQLite | 日付検索等の効率化のため。 |
| ノート (Markdown) | ファイルシステム | 他のMarkdownエディタとの互換性を保つため。メタデータはDB管理も検討。 |
| マインドマップ | SQLite | JSON形式のコンテンツデータとしてDBに格納（または専用独自ファイル）。 |

### 4.2. データ同期への考慮

将来的な分散環境への対応のため、以下のルールを設ける。

- **ID体系**: 全エンティティのプライマリキーには `UUID` または `ULID` を使用し、AUTOINCREMENTは使用しない。
- **監査カラム**: 全テーブルに `created_at`, `updated_at`, `deleted_at` を持たせ、論理削除および更新履歴の追跡を可能にする。

## 5. ディレクトリ構成

ソースコードは以下の構成で管理する。

```
root/
├── src/                     # Frontend (React)
│   ├── components/          # 機能別UIコンポーネント
│   │   ├── Books/           # 書籍管理
│   │   ├── Calender/        # カレンダー
│   │   ├── Dashboard/       # ダッシュボード
│   │   ├── GanttChart/      # ガントチャート
│   │   ├── MindMap/         # マインドマップ
│   │   ├── Notes/           # ノート
│   │   ├── Settings/        # 設定
│   │   └── ToDoList/        # タスク管理
│   ├── tauri/               # Backend API Wrapper (TypeScript)
│   ├── ui/                  # 共通UIコンポーネント (DropDown, ContextMenu等)
│   │   └── shared/          # ドメイン非依存の共有コンポーネント (MarkdownRenderer等)
│   ├── context/             # React Context (Toast等)
│   ├── hooks/               # カスタムフック (useReadingMemos等)
│   ├── type/                # TypeScript型定義
│   ├── utils/               # ユーティリティ
│   └── assets/              # 静的リソース
├── src-tauri/               # Backend (Rust)
│   ├── src/
│   │   ├── commands/        # 各種機能のロジック実装
│   │   │   ├── books/       # 書籍管理
│   │   │   ├── calendar/    # カレンダー
│   │   │   ├── mindmap/     # マインドマップ
│   │   │   ├── notes/       # ノート
│   │   │   ├── notification/# 通知
│   │   │   └── task/        # タスク管理 (sql/配下にDB操作)
│   │   └── lib.rs           # Tauriコマンド登録・状態初期化
│   └── tauri.conf.json      # Tauri設定ファイル
└── docs/                    # ドキュメント (本書含む)
```
