# Notes (ノート)

Markdown形式でテキストを作成・保存できる機能です。

## 機能

* **ディレクトリ管理**:
  * サイドバーでフォルダを作成し、ノートを階層的に管理できます。
* **マークダウン編集**:
  * エディタは分割表示に対応しており、プレビューを見ながら執筆できます。
* **シンタックスハイライト**:
  * コードブロック（` ```javascript ` など）内のコードが、言語に応じて色分け表示されます。
* **スクロール同期**:
  * エディタ側をスクロールするとプレビュー側も追従し、逆も同様です。
* **ファイル操作**:
  * 新規作成、名前の変更、削除が可能です。
  * ファイルはローカルの `Documents/NorunosNotes` に保存されます。
